# Explicit development acceptance

`tests/acceptance/j04-gates.json` maps every A–S flow to actual named assertions.
Vitest emits separate unit/security and real PostgreSQL JSON reports under ignored
`.jarvis/acceptance/`. `npm run test:j04:go` requires both successful, non-skipped
suites and every named assertion. It prints a consolidated A–S result, source SHA
and Actions run ID. Missing evidence or a failed assertion returns nonzero. CI runs
this after browser, queue, outage/recovery and shutdown checks. The Python job must
also pass. No test result automatically merges or changes milestone status.

The synthetic provider test captures the minimized context only. D5/local-only/
never-external records and unrelated fields are excluded before invocation; an
unsatisfied policy raises a deterministic denial. This does not enable a real
external model connector. Data-access audit adds classification and inclusion/
exclusion counts, not context payloads.

Protected storage checks migration compatibility and pgvector before execution.
Vault/encryption and object failures propagate through the existing fail-closed
gateway; health reports these component failures. PostgreSQL and Redis lifecycle
tests remain part of the existing CI service drill. PostgreSQL fixtures are isolated
synthetic databases, and temporary fault injection is restored in finally blocks.

Development limits: bounded record/object/export sizes; backup snapshots at most
10,000 rows per table and 10 MB encoded; no silent audit truncation in export.
Backup expiry/purge eligibility is metadata evidence, not a claim of independently
immutable or physically erased off-host copies. API restore has no caller-selected
production destination. Default destructive-operation registry is empty.

Unvalidated production concerns remain: HSM/KMS custody, physical A4 ceremonies,
independently immutable/offline backups, PITR, multi-region recovery, hostile-process
containment, real connector credential rotation, secure enclaves and regulatory
retention. J0.5/J1 remain blocked until an explicit development GO decision.
