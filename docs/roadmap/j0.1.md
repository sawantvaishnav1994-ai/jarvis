# J0.1 — Repository and engineering foundation

The owner revised J0.1 on 2026-09-01. This checklist describes the TypeScript
monorepo; it does not inherit Python runtime security features merely because
the reference source is preserved beside it.

Acceptance requires a fresh Linux CI checkout to install, start backing services,
migrate, start API/worker/web, pass health checks, complete a queue round trip,
pass tests, survive dependency outage/restart, and stop its Node children. Local
compilation alone is not sufficient. See STATUS and the work log for actual runs.

J0.2 follows: authenticated owner bootstrap/login, device keys, sessions,
revocation, recovery, service/agent identity and trusted execution contexts.
The preserved Python implementation is reference evidence for this work. Keep
personal-data and action endpoints disabled until the TypeScript equivalents
pass integration/security tests.

J0.12 additionally requires independent immutable audit deployment, host-level
worker containment/stop evidence, complete recovery/export/delete/provider and
storage migration evidence, version freeze and owner Foundation v1 GO.
