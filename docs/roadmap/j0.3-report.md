## Production limitations

- Development acceptance uses synthetic owner/device credentials and mock tools;
  it does not enroll the real owner or deploy production infrastructure.
- Hardware A4, P5/R5/Z5 critical execution stays denied pending stronger ceremonies.
- No hostile-worker sandbox, guaranteed process containment or OS network firewall
  is claimed. Policy flags govern registered execution paths.
- Real external effects need durable dispatch, idempotency, revocation fences and
  uncertain-outcome reconciliation before activation; no network effects run
  inside the identity transaction.
- Append-only audit under database privileges/triggers is not independently
  immutable storage. Independent archives and off-host disaster recovery remain open.
- Governance state is deliberately bounded; capacity exhaustion fails closed.
  Large-scale partitioning, multi-node anti-rollback and maintenance remain future work.
- Full field-level production enforcement and financial connectors are deferred;
  restrictive contracts are present without claiming unavailable integration.
- Branch ruleset enforcement remains unavailable under the existing GitHub plan.
