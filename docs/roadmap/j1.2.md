# J1.2 Context Assembly Engine

Status: DEVELOPMENT — J1.2 ONLY

Protected baseline: `8b9e3a581eadca76f0f38d8ed24989668adf0b19`

## Objective

Build the deterministic, fail-closed context assembly layer that selects only authorized, relevant and disclosure-eligible sources for a conversation turn.

## Required behavior

1. Bind every assembly request to owner, conversation, session, turn, security epoch and operating mode.
2. Accept candidate sources only through typed, platform-neutral contracts.
3. Enforce owner and optional project isolation; IDs never grant authority.
4. Enforce D0-D5 classification ceilings; D5 never enters generic model context.
5. Respect disclosure eligibility, privacy mode, retention, expiry and session-only boundaries.
6. Exclude stale, deleted, revoked, malformed or provenance-deficient sources.
7. Treat prompt/tool/web/model-derived content as untrusted data, never as instructions that can override system policy.
8. Apply deterministic priority and budget selection with stable tie-breaking.
9. Produce provenance-bearing source digests/references and exclusion reasons without leaking prohibited content.
10. Remain provider-neutral and client-neutral.
11. Fail closed when authoritative session/epoch/mode binding is invalid.
12. Preserve NEVER_STORE: transient context may be used for the active turn but must not become durable context cache/audit plaintext.

## No migration decision

J1.2 introduces no database migration. Context assembly is a deterministic runtime transformation over already-authorized source snapshots. Durable content remains in the existing J0/J1 storage substrates; J1.2 does not add a duplicate context store.

## Explicit exclusions

- J1.3 production model orchestration
- memory retrieval implementation beyond source-adapter interfaces
- tool execution or approval continuation
- response streaming implementation
- final chat/mobile UI
- autonomous behavior

## Mobile compatibility

The context engine is client-neutral. A trusted phone and trusted web client must receive the same authority and disclosure decisions for equivalent requests. The phone UI itself remains J1.11.
